# 레벨업 (프로토타입)

20~30대를 위한 게임형 자기계발 앱. 미션을 **앱 카메라로 인증** → 경험치 획득 → 나와 캐릭터가 함께 레벨업.

- React 18 + Vite + Tailwind CSS, 모바일 390px 기준, Duolingo 스타일 UI
- 데이터는 모두 더미(`src/data/dummy.js`)

## 실행
```bash
npm install
npm run dev      # http://localhost:5173 (같은 와이파이의 휴대폰은 표시되는 Network 주소로 접속)
```
> 카메라(getUserMedia)는 **HTTPS 또는 localhost**에서만 동작합니다. 휴대폰 실기기 테스트는 HTTPS로 배포(Vercel/Netlify 등)해서 확인하세요.

## 화면
1. **시작 화면**: 떠다니는 Lv.1 마스코트 + 슬로건 + 시작하기 → 페이드 전환
2. **홈 화면**: 프로필/스트릭/젬 → 레벨·XP 배너 → 캐릭터(능력치 체력·지식·마음) → 미션 경로(노드 탭 → 인증하기) → 주간 출석 → 하단 탭

## 미션 인증 규칙 (카메라)
- 앱 내 카메라로 **지금 찍은 사진만** 인증 (갤러리 업로드 UI 없음)
- 필터·보정·뷰티 기능 없음, 원본 프레임 그대로 저장
- 촬영 시각 + 미션명을 사진에 직접 새김, 인증 데이터에 `source: 'in-app-camera'`, `filter: 'none'` 기록
- 카메라 없는 PC 시연용으로만 "(프로토타입) 카메라 없이 시연" 버튼 제공 (`source: 'demo'`)

## 레벨 규칙
- 다음 레벨 필요 XP = 현재 레벨 × 100
- 더미 유저는 Lv.3 / 280 XP → 미션 하나만 인증해도 레벨업 연출을 볼 수 있음
- 캐릭터: 레오파드 게코 '레오' (Lv.3 새싹 → Lv.5 머리띠 → Lv.7 왕관, 상점 꾸미기)
- 연속 인증 콤보: 콤보마다 +5 XP 보너스(최대 +20), 2콤보부터 불꽃 연출
- 능력치(체력·지식·마음)는 삼각형 레이더 차트로 표시
