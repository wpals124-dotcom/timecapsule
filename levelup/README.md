# 레벨리 (LEVEL + DAILY) · 프로토타입

20~30대를 위한 게임형 자기계발 앱. 미션을 **앱 카메라로 인증** → 경험치 획득 → 나와 캐릭터가 함께 레벨업.

- React 18 + Vite + Tailwind CSS, 모바일 390px 기준, Duolingo 스타일 UI
- 데이터는 모두 더미(`src/data/dummy.js`)

## 다른 컴퓨터 · 휴대폰에서 실행하기

| 방법 | 이렇게 하세요 | 카메라 |
|---|---|---|
| **① 파일 하나로 실행** | `levelup/standalone/index.html`을 받아서 더블클릭 (설치 · 인터넷 불필요, 글꼴만 온라인) | 휴대폰 기본 카메라 열기 / 시연 모드 |
| **② GitHub Pages (추천)** | 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 main에 반영될 때마다 자동 배포. 타임캡슐은 `https://wpals124-dotcom.github.io/timecapsule/`, 레벨업은 `https://wpals124-dotcom.github.io/timecapsule/levelup/` | 앱 안 실시간 카메라까지 동작 (HTTPS) |
| **③ 휴대폰 앱처럼 설치** | ②의 주소를 휴대폰에서 열고 **홈 화면에 추가** (iPhone: 공유 → 홈 화면에 추가 / 안드로이드: ⋮ → 앱 설치) | ②와 같음 |
| **④ 개발 PC에서 실행** | 아래 "개발 실행" 참고 | localhost에서 동작 |

파일 하나 버전 다시 만들기: `npm run build:single` → `standalone/index.html` (Pages가 "브랜치에서 배포" 모드여도 `.../timecapsule/levelup/standalone/` 주소로 열림)

## 개발 실행
```bash
npm install
npm run dev      # http://localhost:5173 (같은 와이파이의 휴대폰은 표시되는 Network 주소로 접속)
```
> 카메라(getUserMedia)는 **HTTPS 또는 localhost**에서만 동작합니다. 휴대폰 실기기 테스트는 HTTPS로 배포(Vercel/Netlify 등)해서 확인하세요.

## 화면
1. **시작 화면**: 떠다니는 Lv.1 마스코트 + 슬로건 + 시작하기 → 페이드 전환
2. **홈 화면**: 프로필/스트릭/젬 → 레벨·XP 배너 → 캐릭터(능력치 체력·지식·마음) → 미션 경로(노드 탭 → 인증하기) → 주간 출석 → 하단 탭

## 미션 인증 규칙 (카메라)
- 앱 내 카메라로 **지금 찍은 사진만** 인증 (갤러리 업로드 UI 없음)
- 필터·보정·뷰티 기능 없음, 원본 프레임 그대로 저장
- 촬영 시각 + 미션명을 사진에 직접 새김, 인증 데이터에 `source: 'in-app-camera'`, `filter: 'none'` 기록
- 카메라 없는 PC 시연용으로만 "(프로토타입) 카메라 없이 시연" 버튼 제공 (`source: 'demo'`)

## 캐릭터 · 알 시스템
- 시작하면 일반 등급 3종(햄찌·달이·레오) 중 1마리를 무료로 선택
- 알 등급: 일반(55%, 100 XP) · 희귀(28%, 200 XP) · 영웅(13%, 350 XP) · 전설(4%, 500 XP)
- 레벨업하면 랜덤 등급 알 1개 획득, 미션으로 얻은 XP가 부화기 속 알을 데움
- 부화하면 그 등급에서 아직 없는 친구가 등장 (다 모았으면 💎 보상)
- 수집 친구 8종: 햄스터 햄찌, 수달 달이, 레오파드 게코 레오(일반) / 복어 뽀글이, 흰머리오목눈이 눈송이(희귀) / 우파루파 우파, 도베르만 도비(영웅) / 아기 북극곰 북극이(전설)
- 부화장 탭: 부화기, 보유 알, 등급표, 친구 도감(함께할 친구 변경)

## 친구 레벨 · 진화
- 친구마다 레벨이 따로 있고, 미션 경험치를 함께하는 친구도 똑같이 받음 (필요 XP = 친구 레벨 × 50)
- 진화 3단계: 아기(Lv.1~2, 알껍데기) → 성장기(Lv.3~5, 새싹) → 완전체(Lv.6+, 망토·왕관·오라)
- 진화 순간 전용 연출, 홈의 "진화 보기"나 도감에서 친구를 누르면 진화 단계표 확인
- 첫 친구는 Lv.2에서 시작해 미션 하나로 첫 진화를 볼 수 있음, 새로 부화한 친구는 Lv.1 아기

## 커뮤니티
- 하단 탭 '커뮤니티' 안에 하위 탭: 인증 피드 / 내 크루 / 리그
- 인증 피드: 가입한 크루의 인증샷, 크루별 필터, 좋아요·응원
- 내 크루: 가입한 크루(오늘 인증률), 추천 크루 가입
- 미션 인증 후(완료 시트, 홈 미션 시트, 미션 탭) 인증 사진을 원하는 크루에 한마디와 함께 공유 (공유 보상 💎10)

## 레벨 규칙
- 다음 레벨 필요 XP = 현재 레벨 × 100
- 더미 유저는 Lv.3 / 280 XP → 미션 하나만 인증해도 레벨업 연출을 볼 수 있음
- 캐릭터: 레오파드 게코 '레오' (Lv.3 새싹 → Lv.5 머리띠 → Lv.7 왕관, 상점 꾸미기)
- 연속 인증 콤보: 콤보마다 +5 XP 보너스(최대 +20), 2콤보부터 불꽃 연출
- 능력치(체력·지식·마음)는 삼각형 레이더 차트로 표시
